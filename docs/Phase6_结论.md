# Phase 6 结论：参数扰动鲁棒性

## 1. 实验边界

由于外部跨相机 RAW 数据下载链路不稳定，本阶段先完成 SID Sony 内部的传感器参数扰动实验。该结果称为“参数扰动鲁棒性”，不等同于真实跨相机泛化。

固定模型为：

`checkpoints/phase4_learning/b48_bs12_fair/raw_denoiser_best.pt`

扰动包括曝光增益、R/B 白平衡、归一化黑电平和额外异方差噪声。评价均相对 SID 长曝光参考。

## 2. ISO 200

测试 pair：`0,14,74`。

| 扰动 | PSNR | SSIM | DeltaE | 梯度 |
|---|---:|---:|---:|---:|
| 基线 | 32.306 | 0.84042 | 3.927 | 0.73822 |
| 曝光增益 +5% | 32.295 | 0.84482 | 3.965 | 0.74443 |
| 曝光增益 -5% | 32.020 | 0.83449 | 3.948 | 0.73152 |
| R 白平衡 +5% | 32.361 | 0.84032 | 3.856 | 0.74138 |
| B 白平衡 -5% | 32.349 | 0.84195 | 4.003 | 0.73940 |
| 黑电平偏高 1% | 31.024 | 0.84574 | 4.320 | 0.74838 |
| 黑电平偏低 1% | 22.736 | 0.40884 | 8.084 | 0.49903 |
| 额外噪声 1.5 倍 | 22.469 | 0.40021 | 10.174 | 0.45803 |

结论：曝光和白平衡小误差基本可容忍；黑电平偏低和噪声超出训练分布会造成严重退化。

黑电平偏低时，归一化偏差会在曝光补偿后被放大。ISO 200 pair 的增益约为 250，因此归一化误差 `0.01` 对应约 `2.5` 的场景线性偏移，容易造成暗部抬高、错误饱和和颜色失真。

## 3. ISO 8000

测试 pair：`542,556,570`，ISO 8000、曝光增益 `303.03`。

| 扰动 | PSNR | SSIM | DeltaE | 梯度 |
|---|---:|---:|---:|---:|
| 基线 | 24.471 | 0.60379 | 7.851 | 0.73892 |
| 曝光增益 +5% | 24.146 | 0.59945 | 8.026 | 0.73662 |
| 曝光增益 -5% | 24.706 | 0.60804 | 7.734 | 0.74126 |
| R 白平衡 +5% | 24.458 | 0.59743 | 7.783 | 0.73478 |
| B 白平衡 -5% | 24.240 | 0.60727 | 7.552 | 0.74004 |
| 黑电平偏高 1% | 24.435 | 0.59800 | 7.855 | 0.73603 |
| 黑电平偏低 1% | 24.571 | 0.59167 | 7.674 | 0.73590 |
| 额外噪声 1.5 倍 | 22.460 | 0.40520 | 12.263 | 0.61925 |

结论：高 ISO 下 ±1% 黑电平和 ±5% 曝光/白平衡扰动的影响较小，但额外噪声 1.5 倍仍造成明显退化：PSNR 下降约 `2.01 dB`，SSIM 下降约 `0.20`，DeltaE 增加约 `4.41`。

不同 ISO 的差异说明模型敏感性取决于信号分布、裁剪比例、tone mapping 和噪声底，不能只用一档 ISO 的鲁棒性结果外推全部工作条件。

## 4. 工程结论

1. RAW 黑电平、白电平和白平衡必须在输入端严格记录，不能使用粗略常数替代。
2. 噪声模型和训练数据需要覆盖目标 ISO/曝光增益；超出分布时应提供告警或切换策略。
3. 当前模型可以容忍小幅曝光和白平衡误差，但不具备任意噪声强度下的鲁棒性保证。
4. 部署端应记录实际 ISO、曝光增益和 metadata 版本，避免静默输入错误。
5. 本阶段没有证明真实跨相机泛化；真实跨相机数据仍需后续补充。
