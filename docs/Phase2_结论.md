# Phase 2 结论：曝光、颜色与 Tone Mapping

## 已完成

- 从 SID 官方列表自动读取短/长曝光配对及曝光倍率。
- 场景线性数据在 tone mapping 前保留大于 1 的高光余量。
- 实现 Reinhard 全局 tone mapping 和硬裁剪对照入口。
- 建立 PSNR、SSIM、显示亮度分位数、高光/暗部比例和 ΔE2000 指标。
- 实现并验证 LibRaw 相机矩阵到线性 sRGB 的 CCM 推导。

## Pair 0 基线

物理曝光比为 250。无 CCM 时：

- PSNR：21.297 dB
- SSIM：0.39197
- 短曝光中位亮度：0.25469
- 长曝光中位亮度：0.30672
- 短曝光近黑比例：10.05%
- 长曝光近黑比例：0%

启用 CCM 后：

- PSNR：17.610 dB
- SSIM：0.25147
- ΔE2000 mean/p50/p95：14.825 / 14.440 / 26.562

## 工程决策

- 不用单张参考的中位亮度校准结果替代物理曝光比；350 倍位于搜索边界且会继续损害结构。
- 当前正式基线保持 250 倍物理曝光补偿和 Reinhard tone mapping。
- CCM 实现保留，但在没有 RAW 降噪时默认关闭。它会放大短曝光色度噪声，应在 RAW 降噪之后重新验收。
- 当前低 SSIM 的主要原因是短曝光暗部截断和强噪声，而不是高光映射失败。

## 限制

- SID 长曝光不是色卡真值，不能证明绝对色彩准确度。
- 单个场景不能代表整个数据集，后续需要在验证集上汇总。
- 短/长曝光残差同时包含噪声、微小错位和场景变化。
