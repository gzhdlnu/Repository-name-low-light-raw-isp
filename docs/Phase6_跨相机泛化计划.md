# Phase 6：跨相机与跨数据集泛化计划

## 1. 为什么不能直接使用 SIDD 验证当前模型

当前模型输入是：

```text
4 通道 packed Bayer RAW
黑电平/白电平归一化
相机白平衡
曝光增益
```

SIDD 的常用公开版本主要是手机 sRGB 噪声图和参考图。它缺少当前 RAW U-Net 所需的 Bayer pattern、黑电平、白电平和 RAW 曝光元数据，因此不能把 SIDD 图像直接送入当前模型并声称完成跨相机泛化。

如果要使用 SIDD，应该单独建立一个 sRGB-domain denoising baseline，报告为“跨数据集显示域对照”，不能与 RAW U-Net 的结果混成一个平均分数。

## 2. Phase 6 的正确主线

主线目标是：

```text
Sony SID RAW 训练
→ 另一相机/另一传感器的真实配对 RAW 测试
```

候选数据集必须同时满足：

1. 官方公开来源和可追溯许可证；
2. 存在真实短曝光/长曝光或噪声/参考配对；
3. 能读取 RAW 或线性 Bayer 数据；
4. 记录相机型号、ISO、曝光时间、黑白电平或等价元数据；
5. 能按场景或相机隔离测试，避免 patch 泄漏；
6. 数据规模适合当前剩余磁盘，不能直接下载不明的大型压缩包。

优先选择带多相机 RAW 配对的低照度数据集，例如 ELD 类数据集；具体下载前必须核对官方仓库、许可证、文件大小和校验值。

## 3. 不同域的实验边界

### A. RAW 跨相机主实验

复用当前 U-Net 只在满足输入契约时进行测试。需要新增：

- 相机 metadata parser；
- 不同 Bayer pattern 映射；
- 相机独立黑/白电平归一化；
- ISO/曝光增益分组；
- 相机内 CCM 默认关闭，单独做颜色验收；
- zero-shot 与少量目标域微调两种结果。

### B. SIDD sRGB 对照实验

单独实现轻量 sRGB denoiser，使用 SIDD 官方验证集。报告：

- 与 sRGB Gaussian/Wiener 对比；
- PSNR、SSIM、LPIPS；
- 不与 SID RAW U-Net 直接横向排名；
- 明确这是显示域噪声泛化，不是 RAW ISP 跨相机结果。

## 4. Phase 6 的验收标准

至少完成一种真实跨设备实验：

- 零样本测试有完整失败案例；
- 目标相机的输入解析和通道顺序有检查报告；
- 同一模型在 SID 与目标数据集的退化按 ISO/相机分组统计；
- 明确退化来自噪声分布、颜色矩阵、Bayer pattern 还是曝光标定；
- 不把不同域的结果混成一个总平均数。
