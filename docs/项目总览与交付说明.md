# 低照度 RAW-to-sRGB ISP 项目总览

**作者：** Guozh  
**项目定位：** 部署感知型低照度 RAW ISP 原型  
**数据集：** SID Sony 官方 RAW 配对数据

## 最终目标

输入相机低照度短曝光 RAW，输出可视化 sRGB 图像。系统包含 RAW 解码、黑电平校正、Bayer packing、曝光补偿、RAW 域降噪、去马赛克和 tone mapping，并通过客观指标、失败案例和 GPU 批量推理验证工程可用性。

后续开发不新增互相割裂的阶段，统一按 `docs/工程主线与补全计划.md` 补全 Phase 1 RAW 前端、Phase 2 颜色重建与 Phase 7 YCbCr/媒体输出后端。

## 已完成能力

| 阶段 | 主要任务 | 当前结论 |
|---|---|---|
| Phase 2 | RAW 解码、曝光、白平衡、CCM、tone mapping | 基础 pipeline 可用；CCM 暂不默认开启 |
| Phase 3 | Poisson-Gaussian 噪声建模、Gaussian/Wiener 降噪 | 噪声感知 Wiener 稳定优于固定 Gaussian |
| Phase 4 | 4 通道 RAW 残差 U-Net 训练 | U-Net 在 SID 测试场景显著优于传统基线 |
| Phase 5 | PSNR、SSIM、DeltaE、LPIPS、色度和暗部指标 | 采用多指标和失败案例，不只看单一 PSNR |
| Phase 6 | 曝光、白平衡、黑电平和噪声扰动鲁棒性 | 小幅参数误差可容忍；额外噪声和黑电平偏低风险高 |
| Phase 7 | CUDA、tile batching、ONNX 交换格式、批量推理 | PyTorch CUDA 为当前正式后端；ONNX 仅作兼容性验证 |

## 正式默认配置

```text
模型：checkpoints/phase4_learning/b48_bs12_fair/raw_denoiser_best.pt
后端：PyTorch CUDA + AMP
tile：512，halo：32，tile batch：6
pipeline：RAW 降噪 -> 白平衡 -> 去马赛克 -> Reinhard tone mapping
CCM：关闭（保留为实验分支）
```

## 已验证的工程结果

- SID 官方 train/val/test 场景无交集：161/20/50。
- RTX 3060 Ti 8 GB 上，tile batch=6 峰值显存约 4.27 GiB。
- ISO 200 六场景批量推理吞吐约 0.40 images/s。
- ISO 8000 三场景批量推理吞吐约 0.42 images/s。
- tile batching 相比单 tile 推理降低了平均模型推理时间。
- 最终跨 ISO Release Smoke Test：6/6 成功，模型推理 mean/p50/p95 为 0.541/0.543/0.552 s，峰值显存 4.273 GiB。

## 不能过度宣称的内容

- 当前尚未完成真实跨相机 RAW 泛化；Phase 6 的外部 SIDD RAW 因下载受阻未接入。
- 当前性能是工作站 GPU 原型基线，不是相机 SoC、车载 ECU 或量产 ISP 指标。
- ONNX Runtime 当前使用 CPU provider，不能据此宣称 GPU 加速；正式部署基线仍是 PyTorch CUDA。
