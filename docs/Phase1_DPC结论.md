## 1. 已完成内容

- 在R/G1/G2/B packed Bayer平面内独立检测，修复值只来自同CFA颜色邻域；
- 使用local median、MAD、相对/绝对阈值检测孤立hot/dead pixel；
- 使用水平、垂直和两条对角线中梯度最小的方向插值；
- 建立合成hot/dead pixel注入、precision、recall、F1和修复MAE；
- 完成ISO 200/8000九个独立SID场景的触发率与固定坐标复现审计；
- 比较四档动态DPC阈值。

## 2. 合成验收

初版合成注入结果：

```text
precision=1.00000
recall=1.00000
F1=1.00000
repair MAE=0.00077985
正常像素改动比例=0%
```

阈值标定脚本中的第二组合成样本结果为precision `1.0`、recall `0.99375`。四档阈值结果相同，说明当前0/1极端坏点注入适合检查基本正确性，但不足以区分严格阈值对弱缺陷的漏检风险。

## 3. 真实RAW审计

### 3.1 当前基线阈值

- ISO 200代表场景触发率总体较低，但场景间差异明显；
- ISO 8000平均触发率约`0.14968%`，最大约`0.17409%`；
- 触发图在ISO 8000暗部大面积散布，属于明显随机噪声误检。

### 3.2 严格阈值

配置：

```text
absolute_threshold=0.004
relative_threshold=0.10
mad_scale=12
```

结果：

- ISO 200触发`1–63`点，最大触发率`0.00051976%`；
- ISO 8000触发`2091–3225`点，触发率`0.01725%–0.02661%`；
- ISO 8000仍在暗部呈随机、近似全图分布，数量与空间形态均不适合作为坏点表；
- 只有11个坐标复现3次，且刚好对应3个ISO 8000样本；
- 没有坐标跨ISO复现4次以上，因此没有可靠的永久坏点证据。

## 4. 工程决策

DPC必须分为两个概念：

1. **Static DPC**：根据目标传感器的暗场/平场、多ISO、多温度标定生成固定坏点表；
2. **Dynamic DPC**：单帧只处理极端、孤立且高度可信的脉冲点。

本项目当前没有Sony A7S传感器暗场标定序列，因此不能从SID普通场景构造正式static defect map。

最终策略：

```text
ISO 200：严格动态DPC可保留为实验分支，正式默认仍bypass
ISO 8000：动态DPC默认bypass
Static DPC：保留接口，取得暗场/平场标定数据后启用
普通高ISO随机噪声：交给Wiener/U-Net，不由DPC承担
```

继续无限提高阈值没有工程意义：触发率下降不等于坏点识别更准确，也可能漏掉非饱和坏点。
