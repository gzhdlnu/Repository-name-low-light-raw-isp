# RAW ISP 代码规范

## 文件水印

重要的算法源码、可执行脚本和实验入口在文件头部保留以下信息：

```text
Project: RAW ISP
Task: <当前任务>
Timestamp: YYYY-MM-DD
Author: Guozh
Version: <Phase-任务-v版本>
```

简单的 `__init__.py`、纯数据文件和自动生成结果不重复添加水印。水印只用于源码追踪，不打印到终端，也不写入图像或结果 JSON。实际变更仍然需要通过 Git commit 和实验配置记录。

## 实现要求

- 函数只做一件事，输入输出 shape 和数值范围写在 docstring 中。
- RAW/线性数据默认使用 `float32`，并明确是否在 `[0, 1]` 范围。
- 关键边界做显式检查，避免静默产生 NaN、Inf 或错误 Bayer 排列。
- 随机实验固定随机种子，并保存配置和数据划分。
- 每个 Phase 至少有一个可重复的 smoke test。
- 不在源码中硬编码机器绝对路径；路径从项目根目录或配置文件得到。
- 日志记录项目、作者、版本、输入数据、模型和运行环境。
- 输出必须保存到对应的 `outputs/phaseN_*` 目录；探索性结果放入该 Phase 的 `debug/`，不得堆在 `outputs/` 根目录。
