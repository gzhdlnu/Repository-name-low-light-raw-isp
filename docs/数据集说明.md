# 数据集说明

## SID Sony

- 项目：Learning to See in the Dark（CVPR 2018）
- 官方项目：`https://github.com/cchen156/Learning-to-See-in-the-Dark`
- 当前官方链接：`https://storage.googleapis.com/isl-datasets/SID/Sony2025.zip`
- 规模：约 25 GB 压缩包
- 用途：真实极低照度 RAW 到参考图像的 ISP/增强实验
- 保存位置：`data/raw/SID/Sony2025.zip`

下载脚本：

```bash
cd /home/a/文档/raw_isp_project
bash scripts/download_sid_sony.sh
```

脚本支持断点续传，下载中断后重新运行即可。下载完成后不要直接删除压缩包；先完成校验、解压和 manifest 建立。

注意事项：

- 先确认至少 35 GB 可用空间；解压后还需要额外空间。
- 训练集和测试集必须按官方场景列表划分，不能随机按 patch 切分。
- 官方 README 提醒 10034、10045、10172 存在参考图对齐问题，定量评估时应排除或单独标记。
- 使用数据集发表研究时应引用 Chen et al., “Learning to See in the Dark”, CVPR 2018，并遵守数据集许可和来源要求。
